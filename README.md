

\# Mini Banking Platform



A full-stack banking simulation built to practice modern Angular

and Spring Boot development using professional software engineering practices.



\## Objectives



\- Build a REST API using Spring Boot and Java 21.

\- Apply Hexagonal Architecture and domain-driven design principles.

\- Develop a modern Angular application using Signals, RxJS and standalone APIs.

\- Persist banking data in PostgreSQL.

\- Secure the application with Keycloak and Spring Security.

\- Implement batch processing with Spring Batch.

\- Write automated unit and integration tests.

\- Containerize the development environment with Docker Compose.



\## Technology Stack



| Layer | Technologies |

|---|---|

| Backend | Java 21, Spring Boot |

| Architecture | Hexagonal Architecture |

| Database | PostgreSQL |

| Security | Spring Security, Keycloak, OAuth 2.0 / OIDC |

| Batch Processing | Spring Batch |

| Frontend | Angular, TypeScript, RxJS |

| UI | Angular Material |

| Testing | JUnit, Mockito, Angular testing tools |

| Infrastructure | Docker Compose |

| Version Control | Git, GitHub |



\## Planned Features



\- Customer and bank account management

\- Account balance and transaction history

\- Internal money transfers with transactional consistency

\- Role-based access control

\- CSV transaction import using Spring Batch

\- Periodic statement generation

\- Dashboard and transaction analytics
